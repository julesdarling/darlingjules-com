# Jules Darling Website Design Context

## System

The current site is an intentional white editorial portfolio with giant Xanh Mono display typography, Epilogue body copy, pink CTAs, and large project media. This fork should preserve that identity while making Jules the clear first-viewport subject.

## Typography

- Display: Xanh Mono, used for brand name, large headlines, project titles, and case-study hero lines.
- Body: Epilogue Light (300) for paragraphs, list copy, captions, and metadata; Epilogue Medium (500) for prose emphasis and testimonial attributions. Navigation, CTAs, and controls retain their functional weights.
- Case-study intro paragraphs should read as executive summaries, capped to a comfortable measure and visually subordinate to the headline.

## Layout

- Use generous whitespace and full-width media.
- Keep project pages anchored by a left strategy column and a right media column on desktop.
- On mobile, prioritize readable stacked content and stable spacing.
- Avoid nested cards, decorative gradients, or ornamental chrome.

## Motion

- Motion should feel like editorial pacing: subtle reveal, slight lift, clean timing.
- Animate transforms and opacity only.
- Respect `prefers-reduced-motion`.
- No bounce, elastic, or novelty effects.

## Color

- Preserve the restrained black-on-warm-white system.
- Use the same near-black ink for body copy, bold body emphasis, captions, metadata, display headlines, and navigation. On dark surfaces, match copy to the local light headline color.
- Project imagery carries most of the color.
- Avoid adding a new decorative palette for the personal fork.
